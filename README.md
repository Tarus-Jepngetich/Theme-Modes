# 🎨 Character `var()` and Theming Project

This is a mini front-end project that explores how to use CSS custom properties (`var()`) to create a dynamic and flexible theme system. It demonstrates how to implement light and dark modes (or other themes) using variables defined in `:root`, allowing for clean and scalable styling.

## 🚀 Features

- ✅ CSS custom properties (`var()`) for consistent design tokens
- ✅ Toggleable theme (light/dark)
- ✅ Organized SCSS-like structure using base and variant variables
- ✅ Clean and minimal UI
- ✅ Responsive layout

## 🧪 Technologies Used

- HTML5
- CSS3 (with CSS Variables)
- JavaScript (for theme toggle functionality)

## 🌗 How It Works

- Theme-related colors are stored as variables in `:root`.
- JavaScript is used to toggle classes on the body (`light` / `dark`).
- When a theme class is active, it overrides the default variable values.
- Components and elements inherit these styles dynamically.

## 📚 What I Learned

- How to organize design tokens using CSS variables
- Efficient ways to toggle themes in JavaScript
- Importance of maintainable and scalable styling in UI components
